# PrivatChat 1.1.0 production candidate

- Added provider-independent STUN/TURN configuration with short-lived Coturn credentials.
- Added ICE recovery for network switching and plain-language call failures.
- Added original adaptive, monochrome, notification and splash branding.
- Added system, light and dark appearance modes and a refined Material 3 interface.
- Added attachment cancel/retry, restart recovery, bounded thumbnails and safe attachment opening.
- Hardened release builds with R8/resource shrinking and graceful backend lifecycle handling.
- Preserved dashboard pairing, Gallery, Files, Remote Screen, Room, Redis and the single-socket reconnect state machine.
