# Affiliate demo seed

Startup idempotently seeds editable Facebook, Instagram, and YouTube categories, ten legitimate content-review/QA/public-link-verification templates, and one published demo task per category. The default reward is 0.50 coin and may be changed by an administrator.

The seed contains no artificial engagement, fake-account activity, credentials, passwords, authentication codes, cookies, session tokens, or private keys. Dynamic schema validation also rejects fields that request those sensitive values.
