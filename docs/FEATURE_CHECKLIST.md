# OwnerLink V1 Feature Checklist

## Required
- [x] One owner username/password login
- [x] No signup
- [x] Dashboard
- [x] Multiple devices
- [x] Home Phone / Business Phone separately selectable
- [x] Add Device
- [x] QR pairing
- [x] QR pairing token no time expiry
- [x] QR token single-use after pair
- [x] Durable reconnect token
- [x] Remove/revoke device
- [x] Auto reconnect after network loss
- [x] Online/offline
- [x] Gallery thumbnails
- [x] Gallery original download
- [x] File/folder browsing
- [x] File download
- [x] No permanent server file copy
- [x] Low-FPS remote screenshot
- [x] Tap
- [x] Long press
- [x] Swipe
- [x] Back
- [x] Home
- [x] Recents
- [x] Protected screen respected
- [x] Android Keystore-protected credentials
- [x] HTTPS/WSS deployment
- [x] Docker deployment
- [x] Caddy TLS example

## Optional / must not block
- [ ] Battery %
- [ ] Network state
- [ ] Camera module
- [ ] Microphone module

## Explicitly excluded
- [ ] Payment automation
- [ ] Banking automation
- [ ] OTP capture
- [ ] Credential harvesting
- [ ] Remote shell
- [ ] ADB over internet
- [ ] AI/OCR/search index
- [ ] Public registration
- [ ] Cloud drive synchronization
